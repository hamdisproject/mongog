# BUG-004 — Monaco 0.56 + TS-pinned type manifest is fragile (stale completions)

- **ID:** BUG-004
- **Status:** active
- **Priority:** medium
- **Area:** renderer / monaco / build
- **Found:** 2026-09-06 (code inspection)

## Evidence

- `package.json:79,104` — `monaco-editor ^0.56.0`, `typescript ~5.9.3` (pinned per AGENTS.md landmine 5).
- `scripts/extract-mongo-types.mjs:131-149` — crawls installed `mongodb.d.ts+bson` graph, wraps entry files as ambient `declare module "x"`; header warns `do NOT add top-level import/export` (script vs module augmentation).
- `scripts/extract-mongo-types.mjs:186-191` — manifest key `mongodb@x+bson@y`, regenerated by `prestart/prepackage` (`package.json:29,31`).
- `AGENTS.md` landmines 5-6 — worker import must be `monaco-editor/editor/editor.worker.js?worker`, no `min/vs` CSS, top-level `typescript` namespace (`monaco.typescript.typescriptDefaults`).

## Description

Completions depend on three moving parts staying in sync: (a) installed driver `.d.ts`, (b) generated `mongo-types.manifest.json`, (c) Monaco's bundled TS language service (0.56). A driver bump without regen, a skipped `prestart` (cached dev start), or a TS-version drift between `script-analysis` (TS Compiler API ~5.9) and Monaco's TS yields stale/wrong completions or false-positive editor errors. Sampling failure is advisory by design, so a broken manifest can look like "no field suggestions" rather than an explicit error.

## Impact

- Dev-time / UX only; queries still execute (runtime uses real driver, not types).
- Risk of silent DX regression after `npm update mongodb` or Monaco bump.

## Expected

Driver upgrade either regenerates + validates manifest in CI, or fails loudly.

## Suggested fix

1. CI check: run `extract-mongo-types.mjs` and fail if `src/renderer/generated/mongo-types.manifest.json` diff is non-empty without matching `package.json` driver bump (or assert manifest `key` matches installed versions).
2. Startup self-check (dev only): log manifest `key` vs installed `mongodb+bson` versions on mismatch.
3. Keep pins (`monaco-editor`, `typescript`) — bumps via explicit PR with `spike:monaco-types` latency check (`package.json:54`) + completion smoke.
4. Unit test for `wrapAsAmbientModule`: assert output has no top-level `import/export` (regression guard for landmine 6).
